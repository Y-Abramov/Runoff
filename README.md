# Runoff — Схема стока

Модуль для Топоматик Robur. Анализ направления стока по запроектированным профилям кюветов: стрелки течения на плане, водоразделы, точки сбора воды, контроль уклонов и бессточных понижений. Сеть водоотвода по нескольким моделям с трассировкой и ведомостью по бассейнам.

## Возможности

- Схема стока по кюветам одной дороги: направление течения, водоразделы, точки сбора, плато
- Сеть водоотвода по нескольким моделям (дороги, инженерные сети, структурные линии площадки) со сшивкой в узлы и рёбра
- Трассировка по клику: исход (выпуск/тупик/цикл), накопленная длина, худший уклон
- Проверка норм: уклон ниже нормы, нулевой уклон, бессточное понижение без трубы в допуске
- Учёт труб из моделей `.clv`: сверка отметки лотка с дном кювета
- Ведомости (немодальные, зум по двойному клику, «Таблица на план», экспорт CSV/HTML): участки стока и бассейны сети
- Легенда условных обозначений на план
- Взрыв в штатные примитивы Robur для передачи чертежа без модуля
- Ручная правка подписей грипами, устойчивая к перестроению

## Установка

Через менеджер модулей **ABR | Библиотека модулей** (требуется модуль [AbrModules](https://github.com/Y-Abramov/AbrModules)):

1. Открыть **ABR → Модули → Управление модулями**
2. Найти **Runoff** в каталоге
3. Нажать **Установить** и перезапустить Robur
